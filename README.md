🔗 **Site en ligne :** [lydiaharrache.fr](https://lydiaharrache.fr)

## À propos

Portfolio statique en une page, bilingue (FR/EN), présentant :
- Mon profil et mon parcours (Power Platform, BI, réseaux)
- Mon expérience professionnelle et mes projets
- Mon expérience et mes matières d'enseignement
- Mon CV téléchargeable
- Un formulaire de contact fonctionnel

## Stack technique

- **HTML / CSS / JavaScript** — pas de framework, un seul fichier `index.html`
- **Formspree** — pour l'envoi des messages du formulaire de contact
- **GitHub Pages** — hébergement gratuit
- **OVH** — nom de domaine (`lydiaharrache.fr`) et boîte mail pro (`contact@lydiaharrache.fr`)

## Structure du repo

```
├── index.html          # Le site (tout est dans ce fichier : HTML, CSS, JS)
├── Lydia_Harrache.pdf   # CV téléchargeable depuis le site
└── README.md            # Ce fichier
```

## Modifier le site

1. Éditer `index.html` (soit directement sur GitHub via l'icône crayon, soit en local puis ré-uploader)
2. Cliquer **"Commit changes"**
3. Le site se met à jour automatiquement sur [lydiaharrache.fr](https://lydiaharrache.fr) en 1 à 2 minutes
